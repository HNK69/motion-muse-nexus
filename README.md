## 🚀 Running Locally

Clone the repository:

```bash
git clone https://github.com/HNK69/motion-muse-nexus.git
```

Move into the project:

```bash
cd motion-muse-nexus
```

Install dependencies:

```bash
bun install
```

Start the development server:

```bash
bun dev
```

Visit:

```
http://localhost:8080
```
